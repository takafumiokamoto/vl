# Architecture

## 全体像

Goで書いたコアと、プラットフォームごとのレイヤー（プラットフォームレイヤー）を組み合わせる。

```
Chrome拡張 ────── Native Messaging ──┐
Firefox/Zen拡張 ─ Native Messaging ──┤
CLI ────────────────────────────────┼── コア（Go） ── 同期 ── 同期サーバー
macOS・Windowsアプリ ───────────────┤
スマホアプリ ──── 組み込み ───────────┘
```

コアは端末ごとに動く。

## コア

UI以外のすべてを持つ。

- Vaultのデータ形式
- 鍵導出と暗号化
- アイテム操作、MFAコード生成、検索
- ローカル保存
- 同期クライアント

## プラットフォームレイヤー

プラットフォームごとに実装する薄いレイヤー。UIと、コアへの中継だけを持つ。

| プラットフォーム     | コアとのつなぎ方                                                     |
| -------------------- | -------------------------------------------------------------------- |
| ブラウザ拡張         | ローカルで動くGoのプロセスとNative Messagingで通信する               |
| CLI                  | コアを直接呼ぶ。デーモン構成にする場合はソケットで接続する（未決定） |
| macOS・Windowsアプリ | 未定                                                                 |
| スマホアプリ         | 未定                                                                 |

## 同期

Vaultの実体はサーバー側に置く。各端末のコアが同期クライアントになり、ローカルにも保存を持つ。プラットフォームレイヤーはサーバーと直接通信しない。

## リポジトリ構成

```
vl/
├── core/        # Goモジュール（go.mod はここ）
├── extension/   # ブラウザ拡張
├── apps/        # ネイティブアプリ、スマホアプリ
└── docs/
```
